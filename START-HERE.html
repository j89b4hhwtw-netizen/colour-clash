COLOUR CLASH · START HERE

Your game, from folder to phone.

An UNO-style online game for 2+ friends, with Regular / No Mercy modes, optional exact-match jump-ins and double plays.

Yes, Android users can play too. iPhone, Android, iPad, Windows, Mac and Chromebook players use the same website link. Phones can add it to their home screens. No Mac or app-store account is needed for this web-app route. An internet connection is required.

1. Extract your download

On your Windows computer, right-click Colour-Clash-Online.zip → Extract All → Extract. Open the extracted colour-clash folder. You should see index.html, config.js, setup.sql and the other files.

Keep this guide open while you work. You do not need to type the game code: it is already included.

2. Create your free multiplayer project

  1. Visit supabase.com/dashboard and sign in (you can use GitHub).
  2. Create an organisation if asked, on the Free plan. Choose New project.
  3. Name it Colour Clash. Create and save the database password privately. Choose a nearby region, such as London if available, and create the project.
  4. Wait for the project to finish starting.
  5. Open Authentication. Find Sign In / Providers (sometimes labelled Providers or Sign-in settings).
  6. Find Anonymous Sign-Ins, switch on Allow anonymous sign-ins and save. Players can then choose names without entering email addresses.

This package uses anonymous sign-in without a CAPTCHA widget. Supabase may rate-limit new players, especially many on one Wi-Fi network. Free-plan quotas apply, and inactive free projects may pause; resume them in the dashboard. This is a private-friends starter, not a large public matchmaking service.

3. Add the multiplayer game code

  1. In Supabase, open SQL Editor → New query.
  2. Click Copy setup code below. Paste all of it into the SQL Editor.
  3. Click Run. A success message (often “Success. No rows returned”) means it worked.

Use a new project for this game. The setup creates protected tables and functions; do not make its tables public or disable their security.

Show the full setup code / copy manually

4. Connect your game to your project

  1. In your Supabase project, open the Connect dialog and find the Project URL and Publishable key. Keys are also under Settings → API Keys.
  2. Paste the two values below. The URL usually looks like https://abcdefgh.supabase.co. The publishable key begins sb_publishable_.
  3. Click Download my config.js. Save it into the extracted colour-clash folder and replace the existing config.js. If it downloads as config (1).js, delete the original placeholder and rename this new file to exactly config.js.
Use the publishable key only. This key is designed to go in a website. Never use a secret key, service_role key or your database password here.

This form works inside this guide. It does not send your values anywhere. Alternatively, edit the two placeholder strings in config.js with Notepad, keeping the quotation marks.

5. Put the files on GitHub

  1. Open github.com/new. Sign in if needed.
  2. Name the repository colour-clash, choose Public, select Add a README file if offered, then click Create repository.
  3. In the repository, choose Add file → Upload files. In an empty repository, use the uploading an existing file link instead.
  4. Open the extracted game folder on your computer. Select the files inside it and drag them into GitHub. Upload the individual files, not the ZIP and not the outer folder. It is fine to upload every supplied file, including this guide and setup.sql.
  5. At the bottom, click Commit changes.

Your repository’s main file list must directly show index.html. If you have to click another folder to find it, your files are one level too deep.

6. Turn on the website

  1. In the repository, open Settings → Pages.
  2. Under Build and deployment, set Source → Deploy from a branch.
  3. Choose branch main and folder / (root), then Save.
  4. Wait for GitHub to publish. It can take several minutes. Refresh the Pages settings page and look for the website address / Visit site.
  5. Open that address. It normally has the form https://YOUR-USERNAME.github.io/colour-clash/. Use your actual link, not this example.

If you see 404, check that the latest Pages deployment has finished, the repository is public, and index.html is directly in the publishing folder. The Actions tab shows deployment failures.

7. Add it to an iPhone home screen

  1. Send yourself your website link and open it in Safari.
  2. Tap Share (the square with an upward arrow; it may be inside the More menu).
  3. Choose Add to Home Screen. If it is missing, scroll down and use Edit Actions to add it.
  4. Enable Open as Web App if shown, then tap Add.
  5. Close Safari and open Colour Clash from its new home-screen icon.

Install before joining a room. Safari and the installed app may use different anonymous player sessions. Keep using the same app or browser for a match.

8. Add it to an Android home screen

  1. Open the same website address in Chrome.
  2. Tap ⋮ → Add to home screen or Install app.
  3. Confirm Install / Add. Alternatively, use the game’s Install app button if Chrome offers it.
  4. Open the new icon to play.

Samsung and other Android phones can play with iPhones. Friends on computers just open the link; they do not have to install anything.

9. Start your first game

  1. The host opens the game, enters a name and chooses the Room settings: Regular or No Mercy, Jump-in on/off, Double play on/off, and optional 25-card elimination in No Mercy (off by default).
  2. Click Create a room. Share the eight-character room code or use Copy invite.
  3. Everyone else opens the website, enters their name and room code, and clicks Join. Their own creation settings do not override the host’s.
  4. When 2+ players have joined, the host uses the arrows below the players to choose their starting order, then clicks Deal the cards. Player 1 starts.
  5. The room’s rules appear above the players. Use How to play for the controls. For double play, tick Play two, then click one of the identical cards.

Each device sees only its own hand. After a refresh, use Rejoin your last room. To test alone, use your normal browser and a private/incognito window; two ordinary tabs share the same player identity.

What the settings mean

Group size and deck scaling: there is no fixed player limit in the game code. It uses complete 108-card Regular or 168-card No Mercy decks. It starts with enough for seven cards per player plus roughly seven per player in reserve. Discards are reshuffled when needed; if all available cards are held, a whole extra deck is added. Device performance and your database plan still limit practical room size.

Regular: familiar colour-matching rules, draw one then play or pass, Skip / Reverse / +2 / Wild / +4. A +4 requires no current-colour cards. No draw-penalty stacking.

No Mercy: a larger deck, draw until playable, escalating draw stacks, optional 25-card elimination, 7 swaps and 0 passes. Extra cards include Discard All, Skip Everyone, coloured +4, Wild Reverse +4, +6, +10 and Colour Roulette.

Jump-in: exact same printed colour and symbol, including an identical wild type. It becomes your move and play continues from you. Jump-ins pause during pending draw stacks and roulette. If two people jump at once, the first accepted move wins.

Double play: discard two exact matches as one move. Draw amounts add (two +2 cards mean +4). Other effects happen once: two skips skip one player; two reverses reverse once; two 7s swap once. After drawing you can play only the drawn card. No Mercy penalty stacking is separate and remains enabled even when double play is off.

This is an independent, custom adaptation for 2+ players, not an official UNO app. There are whole decks scaled to the group, automated ONE CARD penalties, a two-minute timeout and no score/challenge system. Finishing your hand wins immediately before the final card’s action. A roulette timeout chooses red. In No Mercy, reaching 25 stops the draw and eliminates you only when the host enabled that option. Otherwise your hand can grow past 25. Taking a draw-card penalty ends your turn and prevents an immediate jump-in until another card is played. Players who are out can watch and rejoin the next round.

Updating and maintaining it

Edit files in your repository and commit the changes; GitHub Pages republishes them. If the server rules change, run the updated setup.sql too. Ask everyone to return to a new room after a rules update. To change a room’s settings, leave and create a new room; rematches retain the existing settings.

Supabase stores anonymous users and rooms. For an occasional cleanup, remove old rooms using the SQL below (this only removes game rooms older than seven days). Anonymous Auth users are separate and can be managed from the Authentication dashboard.

delete from clash_private.rooms where updated_at < now() - interval '7 days';
